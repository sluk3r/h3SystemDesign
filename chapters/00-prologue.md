## 0.1 双十一零点：一个请求的 200ms 旅程

> **写作提示**：用一次秒杀请求的完整链路（DNS → CDN → 网关 → 应用 → 缓存 → 数据库 → 消息队列 → 下游服务）作为全书的“预告片”。每个环节给出一个悬念：“这里，将在第 X 章详细展开”。

- [ ] DNS 解析：第一跳
- [ ] CDN 边缘节点：静态资源
- [ ] 网关：限流与路由
- [ ] 应用服务：业务逻辑
- [ ] 缓存层：Redis 的热点
- [ ] 数据库：最后的真相
- [ ] 消息队列：异步的世界
- [ ] 下游服务：支付、物流、通知
